# GitHub Learning Resources

一份按学习目标分类的高质量 GitHub 学习资源导航。

本仓库只整理公开项目链接、学习顺序和使用建议，不复制原项目内容。适合放在个人 GitHub 主页、收藏夹仓库，或继续拆分成多个专题仓库。

## 入选标准

- 资源有明确学习价值，不只是工具清单。
- 项目或社区长期被开发者引用，内容结构清楚。
- 优先选择免费、开源、可自学的材料。
- 中英文资源兼收，中文学习路径单独整理。
- 避免堆数量，保留适合长期学习的核心项目。

## 维护建议

- 每月检查一次失效链接。
- 新增资源时先写“为什么值得学”，再放链接。
- 不要把同类资源堆太多，宁可保留 5 个真正会用的。
- 不复制课程正文、书籍内容或原项目 README，大段内容请回到原链接阅读。
