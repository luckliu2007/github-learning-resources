# 工具、资料库和长期收藏

这一页收录的是**“索引型/元资源”**——它们本身不是某一门课，而是帮你在需要时快速定位其它资源的大目录。适合收藏后按需查阅，不适合从头读到尾。

## 推荐资源

| 资源 | 适合人群 | 学习重点 |
| --- | --- | --- |
| [sindresorhus/awesome](https://github.com/sindresorhus/awesome) | 所有人 | 各领域 awesome list 总入口 |
| [free-programming-books](https://github.com/EbookFoundation/free-programming-books) | 所有人 | 免费书籍、课程、播客和资料 |
| [public-apis](https://github.com/public-apis/public-apis) | 做项目的人 | 免费 API 数据源（做项目实践另见 [Web、后端和工程能力](05-web-backend-engineering.md)） |
| [the-book-of-secret-knowledge](https://github.com/trimstray/the-book-of-secret-knowledge) | 运维、安全、工程方向 | 命令行、系统、网络、安全工具索引 |
| [papers-we-love](https://github.com/papers-we-love/papers-we-love) | 进阶开发者 | 经典论文目录 |
| [awesome-cheatsheets](https://github.com/LeCoupa/awesome-cheatsheets) | 所有开发者 | 各语言/框架/工具的速查表合集 |
| [awesome-selfhosted](https://github.com/awesome-selfhosted/awesome-selfhosted) | 爱折腾/想自建服务的人 | 可自托管的开源软件索引 |

## 使用建议

- 这类仓库适合做“索引”，不适合从头读到尾。
- 看到好资源后，先判断是否符合当前学习目标。
- 收藏前写一句用途，避免变成永远不会打开的链接。

## 产出目标

- 建一个 `reading-list.md`。
- 每个链接都标记状态：未开始、进行中、完成、暂缓。
- 每月清理一次不再需要的收藏。
