## 建议学习顺序

1. Java 后端方向：JavaGuide 打基础 → advanced-java 补高并发/分布式 → 对照架构师图谱查漏。
2. 算法方向用 labuladong 建立题型框架，配 hello-algo 看动画理解。
3. AI 方向从 Datawhale 系列挑一条课程线，不要一次打开太多资源。
4. 找中文书用 free-programming-books-zh_CN，别到处搜盗版 PDF。
