# 计算机科学基础

## 推荐资源

| 资源 | 适合人群 | 学习重点 |
| --- | --- | --- |
| [OSSU Computer Science](https://github.com/ossu/computer-science) | 想系统自学 CS 的人 | 类似大学本科的计算机科学课程路径 |
| [CS-Notes](https://github.com/CyC2018/CS-Notes) | 中文学习者、面试准备者 | 计算机网络、操作系统、数据库、Java、算法 |
| [every-programmer-should-know](https://github.com/mtdvio/every-programmer-should-know) | 有编程基础的人 | 工程常识、系统知识、性能和安全基础 |
| [papers-we-love](https://github.com/papers-we-love/papers-we-love) | 进阶开发者 | 经典计算机论文和读书会材料 |
| [free-programming-books](https://github.com/EbookFoundation/free-programming-books) | 所有人 | 免费书籍、课程和学习资料索引 |

## 建议学习顺序

1. 如果想系统补基础，从 OSSU Computer Science 开始。
2. 中文复习和查漏补缺，用 CS-Notes。
3. 工作后补工程常识，看 every-programmer-should-know。
4. 每月读一篇 papers-we-love 中的经典论文。

## 产出目标

- 写一份自己的 CS 学习路线。
- 每个核心主题至少完成一份笔记：网络、操作系统、数据库、算法。
- 用项目或文章解释一个基础概念，而不只是收藏链接。
