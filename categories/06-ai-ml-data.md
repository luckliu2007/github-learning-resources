# AI、机器学习和数据科学

## 推荐资源

| 资源 | 适合人群 | 学习重点 |
| --- | --- | --- |
| [ML For Beginners](https://github.com/microsoft/ML-For-Beginners) | 机器学习新手 | 传统机器学习基础、课程式练习 |
| [AI For Beginners](https://github.com/microsoft/AI-For-Beginners) | AI 新手 | AI 基础概念、神经网络、计算机视觉、NLP |
| [Generative AI For Beginners](https://github.com/microsoft/generative-ai-for-beginners) | 想学生成式 AI 的人 | 大模型应用、提示、RAG、智能体 |
| [OSSU Data Science](https://github.com/ossu/data-science) | 想系统学数据科学的人 | 数学、统计、机器学习、数据工程 |
| [awesome-llm](https://github.com/datawhalechina/awesome-llm) | 中文 LLM 学习者 | 大模型课程、论文、工具和实践资源 |

## 建议学习顺序

1. 先补 Python、线性代数、概率统计基础。
2. 用 ML For Beginners 学传统机器学习。
3. 再学 AI For Beginners 或 Generative AI For Beginners。
4. 中文资料和 LLM 实践可配合 awesome-llm。

## 产出目标

- 做一个小型数据分析项目。
- 做一个机器学习 notebook，并解释模型效果。
- 做一个 LLM 应用 demo，比如问答、摘要或 RAG。
