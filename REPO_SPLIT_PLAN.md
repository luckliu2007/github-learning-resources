# 分类建库建议

如果你想把这份资料拆成多个 GitHub 仓库，可以按下面的方式建库。

| 仓库名 | 用途 | 对应分类 |
| --- | --- | --- |
| `github-learning-resources` | 总导航，放所有分类入口 | 全部 |
| `git-github-starter-kit` | Git、GitHub、开源协作入门 | Git 和 GitHub |
| `computer-science-roadmap` | 计算机科学基础学习路线 | 计算机科学基础 |
| `coding-projects-lab` | 项目式学习和练手项目 | 编程语言和项目实践 |
| `algorithm-interview-notes` | 算法、数据结构、面试笔记 | 算法、数据结构和面试 |
| `web-backend-engineering` | 前端、后端、工程能力 | Web、后端和工程能力 |
| `ai-ml-data-roadmap` | AI、机器学习、数据科学 | AI、机器学习和数据科学 |
| `chinese-dev-learning` | 中文优质开发资源 | 中文优质资源 |

## 推荐做法

先维护一个总仓库 `github-learning-resources`。等某个方向的资料和笔记变多，再拆成独立仓库。

每个独立仓库建议包含：

- `README.md`：资源入口和学习路线。
- `notes/`：自己的学习笔记。
- `projects/`：练手项目说明。
- `progress.md`：学习进度。

## GitHub 仓库简介建议

- `github-learning-resources`: Curated GitHub learning resources for programming, computer science, AI, and engineering.
- `git-github-starter-kit`: A beginner-friendly path to learn Git, GitHub, and open-source collaboration.
- `computer-science-roadmap`: A self-study roadmap for computer science fundamentals.
- `coding-projects-lab`: Project-based programming practice and learning notes.
- `algorithm-interview-notes`: Algorithms, data structures, and interview preparation notes.
- `web-backend-engineering`: Web, backend, and software engineering learning resources.
- `ai-ml-data-roadmap`: AI, machine learning, LLM, and data science learning roadmap.
- `chinese-dev-learning`: High-quality Chinese developer learning resources.
